# Decision records

Tracked engineering/product decisions for budget-app. One file per decision,
named `NNN-short-title.md`. Keep them short and honest — the point is to
remember *why*, not to produce polished docs.

## Status values

- **Open** — under consideration / being trialled; outcome not yet recorded.
- **Accepted** — decided and in effect.
- **Superseded** — replaced by a later decision (link to it).
- **Rejected** — considered and declined.

## Adding a decision

1. Copy the shape of an existing entry (title, Status, Date, then free-form
   sections such as Context/Pain, Idea/Decision, Consequences).
2. Give it the next number and a short kebab-case filename.
3. Add a row to the index above.
